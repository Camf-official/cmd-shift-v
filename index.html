Cmd-Shift-V

macOS 메뉴바에서 동작하는 클립보드 기록 앱입니다. ⌘⇧V 를 누르면 최근에 복사한 텍스트, 이미지, 파일을 다시 고를 수 있습니다.

사용법

  • ⌘⇧V: 기록 창 열기
  • ↑ ↓ 와 Return: 항목 골라 붙여넣기
  • 글자를 입력하면 기록을 검색합니다.
  • 핀 버튼으로 자주 쓰는 항목을 고정하고, 휴지통 버튼으로 지웁니다.
  • 스크린샷을 찍으면 이미지가 클립보드와 기록에 함께 들어갑니다. 설정에서 스크린샷 폴더를 한 번 골라 주세요.

자동 붙여넣기 권한

항목을 고르면 바로 붙여넣으려면 시스템 설정 → 개인정보 보호 및 보안 → 기기 제어 및 데이터 접근(예전 macOS 는 "손쉬운 사용")에서 Cmd-Shift-V 를 허용해야 합니다. 허용하지 않아도 항목은 클립보드에 복사되므로 직접 ⌘V 로 붙여넣을 수 있습니다.

English

Cmd-Shift-V is a clipboard history app for the macOS menu bar. Press ⌘⇧V to bring back text, images and files you copied earlier. For support, please open an issue on GitHub Issues. The app collects no data; see the privacy policy.
